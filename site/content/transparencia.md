# Transparência do projeto

O Tainá é mantido por Zoey de Souza Pessanha, uma pessoa que trabalha no projeto em tempo parcial. A situação muda quando o código, os documentos ou os testes mudam; esta página não é um boletim de progresso diário.

## Código e documentação

O código do Tainá é publicado sob a licença GNU AGPL v3.0. A documentação pública descreve o estado conhecido e as pendências. Consulte o [guia de contribuição](/biblioteca/contribuir/) e o [código de conduta](/biblioteca/codigo-de-conduta/).

O repositório de código no [GitHub](https://github.com/taina-labs/taina) é uma opção para quem quer ler o histórico, abrir uma discussão ou propor uma alteração. Não é necessário usar GitHub para falar com a mantenedora.

## Como o código é feito

Ferramentas de inteligência artificial ajudam a escrever parte do código. A mantenedora revisa as mudanças e responde pelo que é publicado. Testes cobrem partes do projeto, mas não substituem a validação com pessoas e comunidades. As lacunas conhecidas estão na página de [estado atual](/estado/).

## Como participar

Você pode ajudar a revisar um guia, encontrar uma informação que não bate com o produto, testar uma versão quando houver um convite para isso, ou propor uma mudança. Para conversar por e-mail, escreva para [zoey.spessanha@zeetech.io](mailto:zoey.spessanha@zeetech.io). Não é preciso ter conta no GitHub.

O plano atual inclui buscar recursos para contratar um redesign visual do produto antes do lançamento 1.0. Ainda não há financiamento confirmado. Para conversar sobre essa necessidade, use o mesmo contato.

## Corrigir esta página

Se uma informação estiver errada ou desatualizada, envie uma mensagem para o contato acima ou abra uma discussão no [GitHub](https://github.com/taina-labs/taina/issues). A informação sobre o produto vale mais do que manter uma frase antiga no site.
