# Guará

Chat previsto para depois do 1.0.0. Não há serviço, telas ou API de chat implementados; restam schemas legados no código.

Quando existir, a assembleia poderá aparecer no fluxo do Guará, mas propostas, votos e quórum terão regras próprias. Não há promessa de E2E no escopo atual.

Veja o [roadmap do Tekoá](https://github.com/taina-labs/tekoa/blob/main/ROADMAP.md).
