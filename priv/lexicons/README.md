# Lexicons do produto

Definições de lexicon em JSON, no formato ATProto, específicas da caixa Tainá.
Elas são carregadas no boot depois das do kernel (`priv/ypy/lexicons`). Um `id`
repetido aqui sobrescreve a definição do kernel.

As fronteiras atuais estão na [arquitetura do Tekoá](https://github.com/taina-labs/tekoa/blob/main/tecnico/ARQUITETURA.md).
